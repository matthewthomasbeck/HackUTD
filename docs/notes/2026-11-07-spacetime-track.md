## What SpacetimeDB is (slide)

"The reactive backend."
A database that runs the server logic inside it and streams every change to connected clients in real time.
Tables, functions, auth, hosting, and sync are in one system.
The slide claims no glue code (no web server, ORM, cache, or websockets to build), one type system end to end, and multiplayer by default.

Every hacker gets 100,000 TeV of free Maincloud credit (about $38), one per GitHub account.
Redeem it from the QR code on the leaflet, code `HACKUTD2026`.

## Tracks (slide)

$5,376 in prizes across two tracks.
A team can enter both.
Public source code on GitHub is required to win.

- Main track: build your project on Spacetime.
  1st $2,048, 2nd $1,024, 3rd $512.
  Spacetime must power the app's primary functionality, not just chat or player movement.
- ScrabbleBot tournament: write a bot for their Scrabble-style auction game.
  1st $1,024, 2nd $512, 3rd $256.
  Live competition at 10:45 PM Saturday night.
  TypeScript starter, and Rust and C# also work.
  Site: scrabblebot.spacetimedb.com.
  Cayden's separate `ScrabbleBot/` project in the hackathons folder is an entry for this tournament.
